Aplicação web desenvolvida para auxiliar na organização e no acompanhamento de despesas pessoais por ciclos de vencimento.

O projeto surgiu da necessidade de visualizar melhor a distribuição dos gastos ao longo do mês, acompanhar pagamentos e apoiar o planejamento financeiro de forma simples e visual.

## Objetivo

Organizar despesas em diferentes períodos do mês, permitindo visualizar valores previstos, pagamentos realizados, saldo pendente e distribuição dos gastos por categoria.

A aplicação também apresenta recursos de apoio ao planejamento financeiro e simulação de amortização.

## ✨ Funcionalidades

- Dashboard financeiro
- Indicadores de despesas previstas, pagas e pendentes
- Organização das despesas por ciclos de vencimento
- Cadastro de novos lançamentos
- Marcação de contas como pagas
- Exclusão de lançamentos
- Distribuição de despesas por categoria
- Gráficos de acompanhamento
- Simulador de amortização
- Exportação dos dados em JSON
- Armazenamento local no navegador
- Interface responsiva

## 🔄 Organização em Duplo Ciclo

Uma das características do projeto é a divisão das despesas recorrentes em dois períodos principais:

- **Parte 1:** vencimentos concentrados entre os dias 07 e 10
- **Parte 2:** vencimentos concentrados entre os dias 20 e 25
- **Outras despesas:** gastos pessoais, variáveis ou continuados

Essa divisão facilita a visualização do fluxo financeiro ao longo do mês.

## 🔐 Privacidade

A aplicação não utiliza banco de dados remoto.

Os dados cadastrados pelo usuário são armazenados localmente no navegador através do `localStorage`.

A versão pública utiliza somente dados fictícios para demonstração.

> Não utilize informações bancárias, senhas, números de cartão ou outros dados financeiros sensíveis na aplicação.
